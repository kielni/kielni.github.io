# Practical Privacy & Security

**Live site:** https://kielni.github.io/practical-privacy/

## Keyboard shortcuts

| Key | Action |
|-----|--------|
| ← → (or Space) | Previous / Next slide |
| F | Fullscreen |
| Esc | Slide overview |
| S | Speaker notes |
| #/5 in URL | Jump directly to slide 5 |

## Tech

- [Reveal.js 5](https://revealjs.com/) — keyboard, touch, and click navigation; deep-linkable slides
- [Font Awesome 6 Free](https://fontawesome.com/) — all icons (no raster images)
- Plain HTML + CSS, no build step, no framework
